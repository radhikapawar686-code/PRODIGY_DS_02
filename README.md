# PRODIGY_DS_02
Task 2: Data cleaning and exploratory data analysis
Titanic Dataset - Data Cleaning & Exploratory Data Analysis (EDA)
📌 Project Overview

This project focuses on performing Data Cleaning and Exploratory Data Analysis (EDA) on the Titanic dataset. The goal is to understand passenger demographics, identify missing values, and uncover patterns related to passenger survival.

🎯 Objective
Clean and inspect the dataset.
Analyze missing values and data types.
Generate summary statistics.
Visualize survival trends.
Explore relationships between passenger characteristics and survival outcomes.
📂 Dataset

The dataset used is the famous Titanic Dataset, which contains information about passengers aboard the RMS Titanic, including:

Passenger ID
Survival Status
Passenger Class
Name
Gender
Age
Number of Siblings/Spouses
Number of Parents/Children
Ticket Number
Fare
Cabin
Embarkation Port
🛠️ Technologies Used
Python
Pandas
Matplotlib
📊 Analysis Performed
1. Data Inspection
Loaded the dataset using Pandas.
Examined dataset structure using info().
Identified missing values using isnull().sum().
Generated descriptive statistics using describe().
2. Survival Analysis
Counted the number of passengers who survived and did not survive.
Visualized survival distribution using a bar chart.
3. Gender-Based Survival Analysis
Calculated survival rates for male and female passengers.
Compared survival rates through visualization.
4. Age Distribution Analysis
Examined passenger age distribution.
Created a histogram to understand age patterns.
📈 Visualizations

The project includes:

Survival Count Bar Chart
Survival Rate by Gender Bar Chart
Age Distribution Histogram
🔍 Key Insights
Female passengers had a significantly higher survival rate than male passengers.
Most passengers were between 20 and 40 years old.
The dataset contains missing values, particularly in the Age, Cabin, and Embarked columns.
A larger proportion of passengers did not survive compared to those who survived.
